# Mustawfi — مُستوفي

Cloud accounting and point-of-sale system for Syrian retail stores, built by **Vertex System**.

V1 targets single-branch small and medium stores (mobile phone shops first, then supermarkets) where several staff work in separate sections, and everything consolidates to the owner and the main accountant — even when the internet is down.

## Status

Pre-development. The foundation documents are in place; architecture decisions are next.
